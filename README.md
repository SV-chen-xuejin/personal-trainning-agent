# 循动 · 个人运动助理

本地开发版 v0.1，面向个人减脂与运动习惯记录。公众号是最终聊天入口；当前可以先使用本地预览。

## 启动

需要 Node.js 24 或更新版本，不需要安装第三方依赖。

```powershell
cd fitness-assistant
npm start
```

也可以双击 `start.cmd`。启动后打开 http://127.0.0.1:8787 。保持启动窗口运行，Ctrl+C 停止。

## 当前可以使用

- 聊天记录常见运动、时长、饮食、身体状态、体重。
- 同一条消息通过逗号或句号分开多个事件，例如“昨天跑步30分钟，午饭吃了牛肉面，今天腿酸”。
- 支持今天、昨天、前天、昨晚和 YYYY-MM-DD；显式输入 HH:mm 时保存时间，未知时间留空，不编造。
- 查看本周记录、查询昨天运动、自然语言修改和撤销最近一条记录。
- 记录页面按类型筛选、精确修改项目/日期/时间/时长/内容、删除和导出 JSON。
- 保存个人目标、偏好、可用时间和身体限制。
- SQLite 持久化；真实记录默认从空白开始，没有预置健康或运动数据。
- 默认基础规则模式；配置兼容 Chat Completions 的模型后，咨询可结合档案、近期记录及相关对话生成建议。

基础规则识别有限，不是任意自然语言理解。记录回复会列出实际保存的内容，未识别的信息保留在原消息中，但不会自动转成结构化记录。请核对记录列表。当前尚不支持语音、照片、设备同步、自动提醒或训练课程。咨询采用按需反馈，不把吃多了换算成必须加练。

## 试用对话

```text
昨天跑步30分钟，午饭吃了牛肉面
今天18:30 游泳40分钟
今天体重150斤
刚才的运动改成25分钟
查看本周记录
今天适合做什么运动？
删除刚才那条运动
```

档案中的体重与每日称重记录分开，修改档案不会生成一次称重。

## 配置模型（选用）

复制 `.env.example` 为 `.env`，在本机填写：

```dotenv
AI_BASE_URL=https://你的模型服务地址/v1
AI_API_KEY=你的密钥
AI_MODEL=你的模型标识
```

重新启动生效。地址填写到 `/v1` 层级，程序追加 `/chat/completions`。未完整配置时继续使用基础规则。远程地址必须为 HTTPS，本机模型可使用 http://127.0.0.1:端口/v1。

配置模型意味着：发起咨询时，档案、最多40条近期记录和最多8条相关对话将发送至你选定的服务。未配置时没有模型外发请求。模型只提供建议，不写入或删除运动记录。模型失败会回退到基础规则并明确提示。真实模型尚未配置，未完成真实服务联调。

## 公众号接入（等待权限确认）

已实现 `/wechat` 的明文 URL 校验、接收文字、被动回复、签名校验、5分钟时间戳窗口、消息 ID 去重和账号白名单。仅为服务端适配代码，尚未与真实公众号验证，不能认为公众号已经接通。

本机管理页面始终只监听 127.0.0.1。需要微信接入时，可额外配置：

```dotenv
WECHAT_PORT=8788
WECHAT_TOKEN=你在公众号后台设置的Token
WECHAT_ALLOWED_OPENIDS=你自己的OpenID
```

该独立端口仅提供 `/wechat`，不给公网提供管理界面或记录API。只允许白名单里的个人账号访问同一份个人数据；其他关注者无法读取记录。没有白名单不开启额外监听。需要从公众号后台获知个人 OpenID，不能用微信昵称或手机号代替。

实际部署还需要公网可达的服务、反向代理和后台配置，当前没有发布、开防火墙或创建公网隧道。不要把本地预览端口直接转发到公网。

此版**仅支持明文回调模式**，加密/兼容模式会明确拒绝。若账号实际要求加密模式，需要补充 AES 消息适配后再上线。

考虑被动回复时间限制，微信端的模型咨询最多等待约1.8秒；较慢时先给基础反馈，提示发送“结果”获取后台完成的模型建议。没有假设账号拥有客服消息接口，不主动推送结果。微信回调超时与实际接口权限仍须实机确认。

## 数据与结构

```text
core.mjs          记录库、时间处理、记录/咨询逻辑、模型接口
server.mjs        本地管理接口、静态页面、微信适配入口
wechat.mjs        签名、消息解析及 XML 回复
public/           聊天、记录及档案页面
 tests/           核心逻辑及服务路由测试
 data/fitness.sqlite   本地数据库（首次运行生成）
```

默认以北京时间处理自然语言日期。记录保留事件日期、可选时间、录入时间、更新时间和原始文字。项目仅面向一个人自用，不是多用户服务。

备份请先停止服务再复制整个 `data` 文件夹；`.env` 是本机密钥，不应提交或分享。可通过页面导出数据，导出当前包含全部结构化记录及最近100条对话，数据库本身保留完整对话。
